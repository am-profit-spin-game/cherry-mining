# Cherry Mining Starter Frontend

- `index.html`: প্রথম Mini App screen এবং আপনার Monetag SDK
- `style.css`: responsive cherry-themed design
- `app.js`: Rewarded Interstitial-এর `show_12152538()` call

এটি শুধু প্রাথমিক frontend। এখনো balance, mining, referral, tasks, cooldown বা withdrawal কার্যকর নয়। Browser callback দেখে Cherry যোগ করা হবে না; Telegram authentication ও Python backend দিয়ে server-side eligibility/cooldown যাচাই করতে হবে। Bot token, database password বা admin secret GitHub-এ রাখবেন না।
