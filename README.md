# Cherry Mining
Starter Telegram Mini App. All files are in repository root.

## Run
pip install -r requirements.txt
uvicorn main:app --reload

## Important
This is a demo starter only. The in-memory balance resets on restart. Telegram initData signature validation, PostgreSQL persistence, secure referral attribution, and provider-side ad reward verification are not implemented. Do not treat points as money. No deposits, crypto transfers, withdrawals, or guaranteed returns are provided. Never commit bot tokens or database passwords.
